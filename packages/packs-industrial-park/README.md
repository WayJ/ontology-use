# packs-industrial-park

Optional add-on pack. Default **`enabled: false`** — skipped by the harness.

- Placeholder task under `tasks/` exists only to show layout; it is not loaded while disabled.
- Real industrial ontology can be introduced later from a local tree such as
  `/workspace/industrial-park-ontology` — copy only tiny public-safe excerpts, never huge proprietary dumps.

Enable only for private experiments; write results to a non-default `--out` directory.
