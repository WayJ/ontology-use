# 1. 问题与目标

## 1.1 研究问题

大型语言模型与 Agent 在涉及结构化领域知识时，常需**使用本体（Ontology / OWL·RDF）**：回答类型查询、枚举个体、提出受控变更或类型化 Action。实践中路径众多——全文塞提示、RAG、子图检索、工具调用、规则校验、行业 taxonomy 对齐、治理写回、对象集 Action——但缺少在**同一任务集**上可复跑的对照。

本文关注：

> 在固定公开本体任务包上，不同「本体使用」方法（M0–M10）的相对行为如何刻画？何种评测脚手架足以支撑后续真实 LLM 对照？

## 1.2 交付定位（非产品）

本仓库是**研究交付**：

1. 评测集（任务、本体包、金标、指标）
2. 方法矩阵 M0–M10 的可复现 runners + 对照表
3. 本文草稿（成效文档；不要求投稿）

**明确非目标：** 建模 UI、生产 SDK/MCP、Computer Use、依赖 Palantir / Onto Planet / Planeteer 私有 SDK。

## 1.3 成功标准（第一期）

- 本机 `npm run eval` 跑完整 mock 评测并写出方法×指标表。
- 结论只引用本次 `results/`，可复跑。
- 工业园等私有本体为可选 add-on，默认不进评测。

## 1.4 本文结构

相关工作 → 方法矩阵 → 实验（仅引用磁盘上的 `results/`）→ 讨论与结论。
